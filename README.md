# 🍔 Food Court - React Project

## 🌟 About the Project

Food Court is a **basic React project** that showcases a simple food ordering system. Users can browse a variety of food items, add them to their cart, and view their selections in a dynamic UI.

## 🚀 Features

✅ **Food Menu Display** – List of available food items.  
✅ **Add to Cart** – Select items and add them to the cart.  
✅ **Cart Summary** – View selected items and total cost.  
✅ **Responsive Design** – Works on desktop and mobile devices.  
✅ **React Components** – Built using functional components and hooks.  

## 🛠 Tech Stack

- **Frontend:** React.js, CSS
- **State Management:** useState (React Hooks)
- **Styling:** CSS/Flexbox
- **Deployment:** Vercel/Netlify (optional)

## 🔧 Installation

1️⃣ **Clone the Repository**
```bash
   git clone https://github.com/PraveenBaghelMaurya/FoodCourt.git
   cd FoodCourt
```

2️⃣ **Install Dependencies**
```bash
   npm install
```

3️⃣ **Run the Application**
```bash
   npm start
```
